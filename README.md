# TigerVid has moved to WildVE

This project has been renamed and moved to **[WildVE (Wildlife Video Extractor)](https://github.com/sheneman/WildVE)**.

WildVE is an efficient ensemble-of-models approach to detection of animals in video data, and represents the evolution of TigerVid with support for multiple detection models, configurable ensembles, and improved performance.

**Please visit the new repository for the latest code, documentation, and releases:**

**https://github.com/sheneman/WildVE**

This repository is archived and no longer maintained.
